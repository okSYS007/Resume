# Resume

Два онлайн-резюме Вячеслава Дандали в одном статическом сайте:

- `index.html` — Full Stack Python Developer (главная страница);
- `1c.html` — Программист 1С / Senior 1C Developer.

Между версиями можно переключаться в боковой панели и по ссылке в начале страницы. Содержание адаптировано по двум предоставленным PDF; исходные PDF не публикуются. Для стилизации используется только локальный `style.css`, сборка и установка зависимостей не нужны.

## Локальный просмотр

Откройте `index.html` в браузере. Для проверки через локальный сервер из корня репозитория:

```powershell
python -m http.server 8000
```

После этого доступны `http://localhost:8000/` и `http://localhost:8000/1c.html`.

## Публикация в GitHub Pages

1. Отправьте изменения в ветку `main` репозитория `okSYS007/Resume`.
2. На GitHub откройте **Settings → Pages** и в **Build and deployment → Source** выберите **GitHub Actions**.
3. Дождитесь успешного выполнения workflow **Deploy static content to Pages** во вкладке **Actions**.

Ожидаемые адреса после публикации:

- `https://oksys007.github.io/Resume/` — Full Stack;
- `https://oksys007.github.io/Resume/1c.html` — 1С.

Публикация с этой локальной копии ещё не выполнялась. GitHub Pages автоматически опубликует обе страницы при push в `main`, если источник Pages настроен на GitHub Actions.

## Содержание и поддержка

В Full Stack PDF опыт заканчивается 2022 годом и локация указана как Одесса; в PDF для 1С есть фриланс с 2022 года и локация в Чехии. Страницы сохраняют эти различия, поэтому перед публичным использованием стоит подтвердить актуальность данных. Контактные данные и телефоны рекомендателей будут доступны всем посетителям сайта.

Для изменения содержания редактируйте соответствующий HTML-файл; общие стили находятся в `style.css`. Есть адаптация для узких экранов и печати из браузера.
